Ablauf

1. User klickt "Login" in einer beliebigen App
2. App leitet zu Keycloak weiter
3. User gibt Passwort bei Keycloak ein
4. Keycloak gibt Token an App zuruck
5. User ist eingeloggt - auch in allen anderen Apps (SSO)

Externen Anbieter anbinden

1. Neuen Client in Keycloak anlegen
2. Client-ID + Secret an Partner geben
3. Partner implementiert OIDC-Login
4. Alle bestehenden User konnen sich sofort einloggen

Zugriffssteuerung

Uber Keycloak-Rollen und Client-Scopes kann pro App gesteuert werden, welche User Zugriff haben
