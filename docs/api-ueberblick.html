Zum Einstieg

Eine API ist eine Steckdose
für Daten.

Sie müssen nicht wissen, wie ein Kraftwerk funktioniert, um eine Lampe anzuschließen. Genauso ist es hier: Unsere APIs sind fertige Anschlüsse. Ihr System steckt sich an – und bekommt genau die Daten, die es braucht.

Hinter allem steht ein redaktionell gepflegter Datenbestand: aktuelle Ereignisse rund um Sicherheit, Einreise, Gesundheit, Umwelt und Reiseverkehr – weltweit, nach Ländern und Regionen sortiert, mit Risikostufe und Zeitraum. Dazu Stammdaten wie Länder, Kontinente, Regionen und Ereignis-Kategorien.

Was Sie damit machen, entscheiden Sie. Manche Kunden holen sich die Daten in ihr eigenes Dashboard. Andere binden einen fertigen Nachrichten-Feed ins Intranet ein. Wieder andere liefern uns ihre Reisedaten und lassen automatisch prüfen, welche Reisenden von einem Ereignis betroffen sind.

Alles beruht auf demselben Datenbestand. Sie entscheiden nur, welchen Anschluss Sie nutzen – und können jederzeit einen weiteren dazunehmen.

Ihre IT braucht typischerweise einen halben Tag, um die erste Abfrage produktiv laufen zu lassen. Alles Weitere ist Feinschliff.

Ohne eigene Entwicklung? Geht auch. Die Feed API (Nr. 04) liefert einen fertigen Nachrichten-Feed, den viele Intranets und CMS ohne Programmierung einbinden können.

Events API

Alle aktuellen Reisewarnungen und Ereignisse – automatisch in Ihrem eigenen System, statt in einem weiteren Portal, in das sich niemand einloggt.

Was sie macht

Die Events API liefert alle aktiven, freigegebenen Ereignismeldungen: von unserer Redaktion erstellte Meldungen, Meldungen unserer API-Partner und automatisch übernommene Informationen aus dem Passolution Infosystem. Jede Meldung trägt eine Risikostufe, einen Zeitraum, eine oder mehrere Kategorien und die betroffenen Länder. Sie lesen nur – verändern können Sie über diese Schnittstelle nichts.

Das können Sie damit

  • Gezielt filtern nach Risikostufe, Land, Kategorie, Region, Zeitraum – und nach der Quelle, also z. B. nur Meldungen eines bestimmten Partners.
  • Im Umkreis suchen: alle Ereignisse in einem Radius um einen Ort – wahlweise über Koordinaten oder einfach über den dreistelligen Flughafen-Code, etwa 250 km um MUC.
  • Länder-Übersicht abrufen mit der Anzahl aktiver Ereignisse je Land – ideal für eine Ampel- oder Kartendarstellung.
  • Stammdaten mitnehmen: Kontinente, Länder, Regionen und alle gültigen Ereignis-Kategorien, damit Ihre Auswahllisten immer aktuell bleiben.
  • Seitenweise abholen – bis zu 100 Meldungen pro Abruf, mit Angabe der Gesamtzahl.

Custom Events API

Ihre eigenen Meldungen – im selben Format, in derselben Qualität und über dieselben Kanäle wie unsere redaktionellen Meldungen.

Was sie macht

Mit dieser Schnittstelle stellen Partner eigene Ereignisse ein: Streiks, Sperrungen, Hausmitteilungen, regionale Hinweise. Sie legen Meldungen an, ändern sie und löschen sie wieder. Angelegt wird mit Titel, Zeitraum, Risikostufe, Kategorie und betroffenen Ländern – Koordinaten, Stichworte und eine eigene Referenznummer sind optional.

Das können Sie damit

  • Eigene Meldungen veröffentlichen – manuell oder automatisch aus Ihrem Redaktionssystem heraus.
  • Bestehende Meldungen pflegen: Zeitraum verlängern, Risikostufe herabstufen, Meldung zurückziehen.
  • Sichtbarkeit wählen: Standardmäßig sehen Sie nur Ihre eigenen Meldungen. Auf Wunsch lesen Sie zusätzlich die Passolution-Meldungen oder die Meldungen einer Partner-Gruppe, der Sie angehören.
  • Im Umkreis suchen – wie bei der Events API, ebenfalls über Koordinaten oder Flughafen-Code.
  • Referenzdaten abrufen: gültige Kategorien und Ländercodes, damit Ihre Meldungen beim Anlegen nicht abgelehnt werden.
Zwei Dinge vorab: Das Anlegen, Ändern und Löschen muss für Ihren Zugang freigeschaltet sein – ohne Freischaltung können Sie nur lesen. Und je nach Vereinbarung erscheint eine neue Meldung sofort oder erst nach redaktioneller Prüfung.

Folder Import API

Damit eine Warnung nicht irgendwo landet, sondern bei den Menschen, die gerade dort sind: Ihre Reisevorgänge in der Plattform.

Was sie macht

Sie übergeben komplette Vorgänge – Kundendaten, Reiseteilnehmer und alle Leistungen: Hotels, Flüge, Kreuzfahrten und Mietwagen. Die Plattform nimmt den Vorgang sofort an und verarbeitet ihn im Hintergrund. Sie erhalten unmittelbar eine Vorgangsnummer, mit der Sie den Stand jederzeit abfragen können: wartend, in Arbeit, fertig oder fehlgeschlagen.

Was dabei automatisch passiert

  • Flughäfen werden aufgelöst: aus „MUC“ wird der vollständige Flughafen samt Koordinaten und Land.
  • Länder werden zugeordnet und geprüft.
  • Eine Reise-Timeline entsteht aus Flügen, Hotels, Schiffen und Mietwagen – der zeitliche Ablauf der Reise.
  • Orte werden verortet: Hoteladressen erhalten Koordinaten für die Kartendarstellung.

Und dann?

Sobald Ihre Reisen in der Plattform liegen, lässt sich die entscheidende Frage beantworten: Wer ist betroffen? Sie können Reisende in einem Umkreis um einen Punkt abfragen, alle Reisenden in einem bestimmten Land ermitteln oder direkt die Vorgänge im Umfeld eines Ereignisses abrufen – dazu gibt es Kennzahlen über die aktuell verreisten Personen.

Feed API

Die einfachste Art, aktuelle Meldungen anzuzeigen – ganz ohne Programmierung und ohne Zugangsdaten.

Was sie macht

Die Feed API stellt die aktuellen Ereignisse als Nachrichten-Feed bereit – im selben Format, das auch Nachrichtenseiten für ihre Schlagzeilen verwenden (RSS und Atom). Die meisten Intranet-Portale, Redaktionssysteme und Feed-Reader binden solche Feeds ohne Entwicklungsaufwand ein. Ein Zugangstoken ist nicht nötig.

Diese Feeds gibt es

Ereignisse

Alle aktiven Meldungen – oder gezielt nur eine Risikostufe, ein Land, eine Kategorie oder eine Region.

Länderlisten

Alle Länder, Länder eines Kontinents, die EU-Mitgliedsstaaten oder die Schengen-Staaten.

Gut zu wissen

  • Mehr als nur Text: Jede Meldung enthält zusätzlich strukturierte Angaben wie Risikostufe, Zeitraum, Kategorie und die betroffenen Länder – auswertbar, wenn Ihr System das nutzen möchte.
  • Aktuell und übersichtlich: Die Feeds werden zwischengespeichert und bei neuen Meldungen automatisch erneuert – maximal 100 Meldungen je Feed, die neuesten zuerst.

Plugin Domain API

Sie bestimmen selbst, welche Websites Ihr Plugin einbetten dürfen – auch wenn es hunderte sind.

Was sie macht

Wenn Sie das Passolution Plugin auf Ihren Websites einbinden, muss hinterlegt sein, welche Adressen das dürfen – aus Sicherheitsgründen funktioniert die Einbettung nur auf freigegebenen Domains. Genau diese Liste verwalten Sie mit dieser Schnittstelle: hinzufügen, ändern, deaktivieren, löschen. Für einzelne Domains ebenso wie für ganze Listen auf einen Schlag.

Das können Sie damit

  • Massenimport: bis zu 1.000 Domains in einem einzigen Aufruf – statt hunderter Klicks im Dashboard.
  • Abgleich statt Pflege: Bestand abrufen, nicht mehr benötigte Adressen entfernen, neue nachziehen – ideal für einen nächtlichen Automatismus.
  • Vorübergehend abschalten: Eine Domain lässt sich deaktivieren, ohne sie zu löschen – etwa während eines Relaunches.
  • Schreibweise egal: Adressen werden automatisch vereinheitlicht – https://, www., Pfade, Portangaben und Großschreibung werden entfernt.
Ihr Schlüssel ist derselbe wie für die Einbettung des Plugins. Sie finden ihn in Ihrem Plugin-Dashboard – ein zusätzlicher Zugang ist nicht nötig.

In vier Schritten
angebunden.

Ziel festlegen

Klären Sie zuerst, was Sie erreichen wollen – anzeigen, auswerten oder liefern. Die Tabelle auf der vorherigen Seite führt Sie in einer Minute zur passenden Schnittstelle.

Ihre IT ruft einmal die gewünschte Adresse auf und sieht sofort, was zurückkommt. Für jede Schnittstelle liegt eine technische Beschreibung bereit, die gängige Entwicklungswerkzeuge direkt einlesen können.

4

Produktiv gehen

Legen Sie fest, wie oft abgefragt wird – meist genügt ein Abruf alle 15 bis 60 Minuten – und wo die Daten in Ihrer Oberfläche erscheinen. Fertig.

Nachschlagen

Die zwölf Begriffe,
die immer vorkommen.

API
Eine Schnittstelle, über die zwei Programme Daten austauschen – ohne dass ein Mensch etwas abtippt.
Endpunkt
Eine feste Adresse innerhalb der Schnittstelle, hinter der eine bestimmte Information liegt, etwa die Liste der Ereignisse.
Token / Schlüssel
Ihr persönlicher Ausweis gegenüber der Schnittstelle. Er gehört wie ein Passwort behandelt.
JSON
Ein Textformat für strukturierte Daten. Software kann es direkt weiterverarbeiten, Menschen können es lesen.
RSS und Atom
Zwei verbreitete Formate für Nachrichten-Feeds. Viele Intranets und Redaktionssysteme können sie ohne Zusatzsoftware anzeigen.
Risikostufe
Die Einstufung einer Meldung: hoch, mittel, niedrig oder rein informativ.
Kategorie
Das Thema einer Meldung – etwa Sicherheit, Gesundheit, Umwelt, Reiseverkehr, Einreisebestimmungen oder Allgemeines.
Umkreissuche
Die Abfrage „Was liegt im Umkreis von X Kilometern um diesen Ort?“ – über Koordinaten oder über einen dreistelligen Flughafen-Code.
Koordinaten
Zwei Zahlen, die einen Punkt auf der Erde beschreiben: Breitengrad und Längengrad.
Seitenweise Abruf
Große Ergebnismengen kommen in Portionen. Sie fragen Seite für Seite ab und erfahren dabei, wie viele Einträge es insgesamt gibt.
Abruf-Limit
Die Höchstzahl an Anfragen pro Minute. Sie schützt die Plattform vor Überlastung und lässt sich bei Bedarf anheben.
Vorgang / Folder
Eine komplette Reise mit allem, was dazugehört: Kunde, Teilnehmer, Flüge, Hotels, Schiffe und Mietwagen.
